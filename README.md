## The entry

Exactly one emoji, standing in for the trip of my dreams:

🌌 — the aurora borealis over a far-northern sky. A bucket-list trip
(Iceland / northern Norway) that a stranger can see at a glance:
specific to one dream rather than any holiday, and a fresh pick next
to the field's beach postcards.

## How it works

`main.py` (Python 3.13, standard library only) writes that single
emoji — U+1F30C MILKY WAY, one character, four UTF-8 bytes, no
newline — to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default), then reads it back
and verifies it byte-for-byte and that it is exactly one non-space
character.

Run it:

```sh
python3 main.py
```
